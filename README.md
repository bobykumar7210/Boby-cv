# Boby Kumar — Resume

A modern, dark-themed online resume built with **HTML** and **CSS**. Designed for both screen and print.

## 🔗 Live

**[bobykumar7210.github.io/Boby-cv](https://bobykumar7210.github.io/Boby-cv)**

## Features

- **Dark premium UI** — gradient accents, micro-animations, glassmorphism cards
- **Print-ready** — clean light layout when printed (`Ctrl+P`)
- **Responsive** — adapts to mobile, tablet, and desktop
- **Single file** — no build tools, no dependencies, just `index.html`

    └── Boby_Kumar_CV_Simple.docx           # DOCX — minimal grayscale version
